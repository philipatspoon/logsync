# logsync – tidskodssynk

Mobilsida för Värdskärmen: läser huvudkamerans tidskod med mobilkameran och skickar synken till datorn.

Öppnas via QR-koden i Värdskärmen (*Synka tidskod → Med mobil (QR)*). Filen innehåller inget manus och inget typsnitt; själva appen körs lokalt på datorn.

Uppdateras genom att köra `python3 build-mobil.py` i Värdskärmens mapp och ersätta `index.html` här.
